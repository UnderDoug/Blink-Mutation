# Blink Ability
Blink is a short-range, physical teleport ability (unaffected by normality), that doubles as an attack if used to pass "through" a hostile creature. Blinking "through" a hostile creature places you on the other side of them and performs an attack. Depending on the source of blink, the attack is either a free action, or deals unavoidable damage.

Renamed (previously "Blink Mutation") and broadly reworked, this mod now includes a plethora of new additions for the game.
